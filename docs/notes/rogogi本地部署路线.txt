## 五、复用 vs 必须重写
可直接复用（零改动或仅格式转换）

- 前端全部代码 （32 文件 / ~15.8K 行）：原样保留，仅调整 API 基址与类型
- `nrc.db` （1.2 MB）：`sqlite3` 直接读取，表结构不变
- `data/map/` ：`base_map.jpg` + 4 个 JSON + 35 个图标
- `data/templates/` ：9 个 PNG 视觉模板
- SIFT-Map-Tracker v0.10.2 ：ONNX 模型与特征资源（外置，不改二进制）
- `rocoflow.db` 表结构 ：`storage.py` 建表语句转写
- 4 个预置工作流 ：`seed.py` 转写为初始化 SQL
- 工作流 JSON schema 与 Node Contract 语义 ：概念层复用，实现重写
必须重写

- FastAPI / uvicorn / websockets / numpy / opencv-python / pillow 全部调用层
- `backend/app/` 全部 Python 模块（含`components.py` 、`sessions.py` 、`api/routes.py` 、`engine/` 、`nodes/` 、`adapters/` 、`hotkeys.py` ）
- `backend/vendor/nrc_ai/` 全部 Python 逻辑（MCTS、效果引擎、`_monolith.py` 3202 行）， 仅数据复用
- Windows 专有交互：DXGI 截图、SendInput、RegisterHotKey
